# Support

Report bugs and request features through the [GitHub issue tracker](https://github.com/mm-lab-dev/azdo-sprint-timeline/issues).

Include the extension version, browser and operating system, the selected Sprint range, the display mode, reproduction steps, and whether the problem also occurs with mock data. A screenshot or a small anonymized Feature / User Story / Task example can help.

For aggregation issues, include each item's type, parent relationship, and Sprint assignment. Mention whether the Story's own Iteration is unplanned or outside the selected range.

Do not include access tokens, authorization headers, private organization URLs, or work item contents you are not allowed to share. This extension is an independent project and is not affiliated with or endorsed by Microsoft.
