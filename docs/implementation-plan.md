# 実装計画

1. 空のリポジトリをAngular 21 / PrimeNG 21で初期化。公式文書・インストールしたSDK型定義を確認。
2. 純粋関数でSprint整列、seed抽出、祖先グラフ、期間集約、クリップ、表示フィルターを実装。受け入れ条件を単体テスト化。
3. モックでSprint等幅軸、階層、表示モード、検索・状態・担当者、異常状態を実装しE2E検証。
4. SDK bootstrapと読み取り専用API adapter、ページング、200件分割、祖先探索、再試行、競合防止を実装。
5. 静的解析・単体・E2E・ビルド・VSIX生成を実行。受け入れ結果と実組織手動検証事項を記録。

実組織へのインストール・公開は実行しない。A14は利用者の手動検証が必要。
